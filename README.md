# Tournament Management System 🏆

An interactive tournament management system developed using HTML, CSS and JavaScript as part of my BTEC IT coursework.

## About the Project

The Tournament Management System is a browser-based system designed to help manage tournament information and participants.

## Features

- 🔐 Login and signup interface
- 👥 Participant and team registration
- 🏆 Tournament/event creation
- 📊 Score submission
- 🥇 Leaderboard
- 📋 Attendance management
- 📁 CSV data export
- ✏️ Add, edit and delete records
- 💾 Local data storage using browser localStorage

## Technologies Used

- HTML
- CSS
- JavaScript
- Browser localStorage
- CSV data export

## What I Learned

Through this project I developed experience with:

- Creating interactive webpages
- Using JavaScript to manage application logic
- Working with forms and user input
- Managing data using localStorage
- Creating CRUD-style functionality
- Building a leaderboard
- Exporting data to CSV
- Designing a user-friendly interface
